# Privacy policy

Regex Find does not collect, send or share any data.

- Page text is processed locally and never leaves the browser.
- Settings and saved patterns are stored in Chrome sync storage. Search history is stored locally. You can clear it in the extension's settings.
- The extension makes no network requests.

Permissions:
- **Access to all sites:** the find bar works on any page and inside iframes.
- **scripting:** tabs that were already open when the extension was installed work without a reload.
- **offscreen:** patterns run in an isolated worker.
- **storage:** settings and history.
- **sidePanel:** the results panel.
- **clipboardWrite:** copying matches.
