# Chrome Web Store listing

**Name:** Regex Find

**Summary:** Find on page with regular expressions. Fast on large pages, and works in iframes, shadow DOM and inputs.

**Category:** Developer Tools

**Description:**

Search any page with JavaScript regular expressions.

- Highlights matches without modifying the page.
- Stays fast on very large pages.
- A runaway pattern is stopped instead of freezing the tab.
- Searches iframes, shadow DOM, inputs and textareas.
- Replace in editable fields, using $1 and $<name>.
- A side panel lists every match with context. Copy them as text or JSON.
- Keyboard shortcuts: Alt+Shift+F opens the bar, Enter goes to the next match, Esc closes it.
- No data leaves your browser.

**Single purpose:** Find and highlight text on the current page using regular expressions.

**Screenshots:** Run `SHOTS=1 npx playwright test screenshot`. They are written to `test-results/shots/store-*.png`.
